# Student Grade Management System

A Python command-line application for managing student academic records.

## Internship Task

The project demonstrates how Python can be used to add student names and marks, store multiple subjects, calculate total and average marks, determine grades, display and search student records, validate marks, and handle invalid input.

## Technologies

- Python 3
- Dictionaries
- Functions
- Loops
- Conditional statements
- Exception handling
- Command-line interface

## How to Run

Make sure Python 3 is installed.

```bash
python student_grade_management.py
```
